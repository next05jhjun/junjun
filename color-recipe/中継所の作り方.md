# カラーレシピ：AIの中継所（Cloudflare Workers）の作り方

AIの鍵は公開リポジトリに書けないので、Cloudflare（無料）に小さな「中継所」を作って、そこに鍵をしまう。
アプリ → 中継所（鍵を付ける・ネクストのメンバーか確かめる）→ Claude（Haiku 5.5）→ アプリ、の順に流れる。写真はどこにも保存しない。

## 1. Claude の鍵を作る（じゅんがやる）
1. https://platform.claude.com を開いてログイン（無ければ登録）
2. 「Billing（支払い）」でクレジットを入れる（最初は 5ドル＝約750円で十分。Haiku 5.5 は1回およそ0.3〜0.5円）
3. 「Limits（上限）」で、1か月の上限を 10ドル などにしておく（使いすぎ防止）
4. 「API Keys」→「Create Key」→ 名前は `color-recipe`。出てきた `sk-ant-…` をコピー（**どこにも貼らない・人に見せない**）

## 2. Cloudflare に中継所を作る（じゅんがやる）
1. https://dash.cloudflare.com でアカウントを作る（メールだけ、カードは不要）
2. 左の「Workers & Pages」→「作成」→「Worker を作成」→ 名前を `color-recipe` にして「デプロイ」
3. 「コードを編集」を押し、中身を全部消して、このリポジトリの `color-recipe/worker.js` を丸ごと貼り付けて「デプロイ」
4. Worker の「設定」→「変数とシークレット」で追加：
   - `ANTHROPIC_API_KEY`（種類：**シークレット**）＝ 1. でコピーした鍵
   - `ALLOWED_SALONS`（種類：テキスト）＝ ネクストのお店のID（カラーレシピの「設定」に出る。2店舗なら `ID1,ID2` とカンマでつなぐ）
5. 上に出ている `https://color-recipe.〜.workers.dev` がアドレス

## 3. アプリにつなぐ
- まず試すとき：カラーレシピの「設定」→「AIの中継所のアドレス」に 2-5 のアドレスを入れて保存
- みんなで使うとき：`color-recipe/index.html` の `DEFAULT_AI_URL = ''` にアドレスを書く（アドレスは秘密ではないので公開してよい）

## 守り
- 鍵は Cloudflare のシークレットの中だけ。アプリやGitHubには出ない
- 使えるのは、サロンストックにログインしていて、`ALLOWED_SALONS` のお店のメンバーの人だけ（Firestore のルールで確認）
- 呼べるのは `https://next05jhjun.github.io` のページからだけ
- それでも心配なら、Claude の管理画面で月の上限を低めにしておく
